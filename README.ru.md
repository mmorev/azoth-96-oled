# Azoth Companion

Open-source компаньон для OLED-дисплея клавиатуры **ASUS ROG Azoth 96
HE** — замена проприетарной утилиты ASUS GearLink Companion. Работает на Windows, macOS и Linux.

*English version: [README.md](README.md)*

## Что это

У клавиатуры ROG Azoth 96 HE есть небольшой тачскрин, с помощью которого можно настраивать саму клавиатуру, а также он может отображать несколько виджетов: часы, заряд батареи ноутбука и индикаторы работы системы, типа загрузки CPU/RAM или скорости вращения вентиляторов.

Виджеты на данной клавиатуре управляются только при помощи ASUS GearLink Companion - устанавливаемого фонового приложения, которое работает только на Windows и настраивается через Web-интерфейс GearLink.

Этот проект — легковесное python-приложение, которое может работать в фоне, легко настраивается и передает на дисплей необходимые для работы виджетов данные.

USB-протокол взаимодействия с клавиатурой был исследован и задокументирован отдельно (см. [Участие в разработке](#если-хотите-предложить-свои-доработки)).

## Возможности

- **Кросс-платформенность** - Windows/MacOS/Linux. GearLink - только Windows.
- **Часы** — синхронизируются с хостом каждую минуту (в клавиатуре нет собственного RTC, часы обновляются только с хоста).
- **Батарея** — процент заряда ноутбука.
- **Индикаторы** — загрузка/температура/частота/напряжение для CPU, GPU, RAM и VRM, а также скорость вращения соответствующих вентиляторов.
  - Индикаторы отображаются в виде плиток с 1 или 2 ячейками.
  - Плитки листаются автоматически либо свайпом вниз (на GearLink свайп работает нестабильно).
  - Перелистывание свайпом задерживает текущую плитку на несколько секунд (таймаут настраивается).
- **Громкость** — При изменении громкости с клавиатуры на OLED отображается громкость хост-системы в реальном времени (на GearLink - с задержкой и пропусками).
  - При Unmute на дисплей также выводится уровень громкости (GearLink не умеет).
- **Счётчик KPS** — нативная плитка со счетчиком нажатий.
- **Graceful Shutdown** — при отключении приложения (Ctrl+C, SIGTERM) виджеты, не работающие офлайн, отключаются.

## Почему не GearLink

|                       | Azoth Companion                           | GearLink           |
|-----------------------|-------------------------------------------|--------------------|
| Платформа             | Windows, macOS, Linux                     | только Windows     |
| Сенсоры               | Только CPU (по состоянию на октябрь 2026) | CPU, GPU, RAM, Fan |
| Отображение громкости | В реальном времени                        | С задержкой        |
| Громкость при Unmute  | да                                        | нет                |
| Graceful Shutdown     | Да                                        | нет                |

## Как это работает

- Приложение опрашивает параметры мониторинга и пушит их в клавиатуру через USB HID
- Приложение прослушивает события с клавиатуры:
  - Изменение громкости (нажатие качельки вверх/вниз) и Mute/Unmute.
  - Свайп по дисплею (пока **только
    вниз** — свайпы влево и вправо обрабатываются нативно на клавиатуре, вверх - сливается с heartbeat-шумом).
  - При обнаружении событий изменения громкости пушит в клавиатуру текущее значение громкости для отображения на оверлее.
- **Приложение не имеет доступа к нажатым клавишам — не является и не может быть использовано как кейлоггер.**
- Взаимодействует
  **только** с дополнительными микроконтроллером клавиатуры (system controller), который управляет дисплеем и тачскрином.

Протокол взаимодействия с контроллером OLED-дисплея исследован через захват трафика с помощью USBPcap и анализ прошивки контроллера. Протокол полностью задокументирован в соседнем репозитории [azoth-96-oled-proto](https://github.com/mmorev/azoth-96-oled-proto).

### Бэкенды:

- Windows читает сенсоры из запущенного [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) (через WMI; `pip install wmi`);
- MacOS использует [macmon](https://github.com/vladkens/macmon) (Apple Silicon, `brew install macmon`);
- Linux — только [psutil](https://github.com/giampaolo/psutil).

Загрузка, RAM, батарея и частота CPU берутся из psutil на всех ОС.

Метрики без работающего бэкенда пропускаются с одним предупреждением в лог — слайдшоу крутит только живые слайды.

## Быстрый старт

Нужны Python 3.10+ и клавиатура, подключённая по **USB**.

```bash
pip install -r requirements.txt        # hidapi + psutil
```

**Сначала закройте GearLink** — иначе приложения будут конфликтовать и приводить к зависаниям дисплея и даже контроллера целиком.

В любом случае, использование приложения полностью безопасно для клавиатуры. В случае сбоев и зависаний, просто переподключите кабель.

На Windows: `taskkill //IM GearLink* //F`.

Проверка работы:

```bash
python main.py --status                  # статус устройства и хоста, ничего не пишет
python main.py --demo                    # тест индикаторов: плитка CPU ходит 0→100→0
python main.py --once --cpu 42 --bat 77  # пуш ручных значений один раз, без обновления
```

Рабочий цикл — часы, батарея и две плитки мониторинга - двойная (CPU+RAM usage) и одинарная (температура ЦП):

```bash
python main.py --clock --battery --monitor --monitor-items cpu.usage+ram.usage,cpu.temp
```

Настройка задержки слайдшоу плиток с метриками:

```bash
python main.py --clock --battery --monitor --monitor-items cpu.usage+ram.usage,cpu.temp --slideshow 3
```

## Параметры командной строки

Полный список — `python main.py --help`. Основное:

**Виджеты** (какие слоты включить; без флагов остаётся только баннер):

- `--banner` — слот 0: баннер/режим музыки/свой bitmap, статичный
- `--clock` — слот 1: часы, синхронизация на границе каждой минуты
- `--battery` — слот 2: батарея ПК (`--bat` включает его автоматически)
- `--monitor` — слот 3: двойной индикатор/слайдшоу; включается сам флагами `--metrics`, `--slideshow`, `--monitor-items`
- `--kps` — слот 4: счётчик клавиш/с, нативно управляется контроллером

**Цикл и слайдшоу:**

- `--interval SEC` — период опроса хоста в обычном режиме, с (по умолчанию 2)
- `--metrics cpu-temp|cpu-ram|cpu` — набор плиток двойного индикатора без слайдшоу: usage+temp (по умолчанию; без сенсора — только usage), usage+RAM («DRAM0»), только usage
- `--slideshow SEC` — листать слайды каждые SEC секунд; смахивание вниз листает вручную и ставит автолистание на паузу 5 с
- `--monitor-items SRC.METRIC[,…]` — слайды в формате «источник.метрика»: источники `cpu/gpu/ram`, метрики `usage/temp/freq/volt/fan`, пары `a+b` — двойная плитка (например, `cpu.usage+ram.usage`); короткие имена вроде `cpu` тоже работают; слайды с датчиками (все temp/freq/volt и `gpu.usage`) требуют LibreHardwareMonitor, без него слайд пропускается с предупреждением; без `--slideshow` список листается каждые 2 с
- `--start 0-4` — какой виджет показать после настройки, номер слота (должен входить в набор включенных виджетов)
- `--brightness 0-100` — переустановить яркость (по умолчанию не трогается)
- `--keep-awake` — будить OLED командой `65 FF` каждые 60 с
- `--no-clock` — не синхронизировать время

**Ручные значения** (тесты без сенсоров):

- `--cpu 0-100`, `--temp °C`, `--ram-val 0-100`, `--bat 0-100`.

**Обновление громкости:**

- `--vol-hz HZ` — частота пушей OSD в окне серии (по умолчанию 12, выше 20 Гц обрезается)
- `--no-volume` — не слушать качелку и не пушить OSD громкости.

**Диагностика:**

`--once` — настройка и один пуш значений без цикла (картинка остаётся на экране)
`--status` — только статус устройства и хоста, ничего не пишет
`--demo` — тест индикаторов (плитка CPU плавно меняется 0→100→0)
`--events` — лог событий качельки/тача
`--evt-dump` — дамп всех 0xFFC0-кадров и TXLOG

**Лог:**

`--log-file [PATH]` — дублировать лог в файл (UTF-8, ротация ~2 МБ × 3); без PATH — `logs/azoth-companion.log` рядом с `main.py`.

## Автозапуск (Windows)

```bash
python scripts/install.py install      # создать задачу "Azoth Companion" на логон
python scripts/install.py uninstall    # убрать её
```

Создаёт задачу планировщика текущего пользователя (старт через `pythonw.exe` при входе с флагами `--clock --battery --monitor --slideshow 2 --log-file`). Прав администратора не требуется. На macOS/Linux ту же командную строку добавьте в автозапуск сессии; встроенного установщика пока нет.
